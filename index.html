01 — About

I am a Software Development Engineer Intern at Keysight Technologies Malaysia, working with the Materials Engineering team on data processing and automation using mostly Python and SQL against SQL Server. I am also a Computer Science undergraduate at Universiti Teknologi PETRONAS.

I like turning messy data into decisions somebody can actually act on, and I like building things that stay simple enough to still make sense a year later. This site is the same idea: plain HTML, CSS and JavaScript, no build step.

Outside coursework I have directed community projects and run the column writing desk at the UTP Journalism Club and also a fair amount of my time goes into organising people and writing clearly, not only into code.
